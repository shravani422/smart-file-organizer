Smart File Organizer

A Python-based command-line application that helps users organize files on their computer through user-provided commands.

Features

- Automatic File Organization: Sorts files into categories based on their file types.
- Folder Management: Creates and manages folders for organized file storage.
- Date-Based Sorting: Organizes files according to their dates.
- Undo Functionality: Allows users to reverse file organization operations.
- Folder Cleanup: Provides an option to delete empty folders.
- Activity Monitoring: Monitors file organization activities.
- Activity Logging: Maintains a record of application activities.

Technologies Used

- Python

How to Run

1. Install Python on your computer.

2. Download or clone this repository.

3. Open the project folder in a terminal.

4. Run the following command:
   
   "python main.py"

5. Follow the instructions displayed in the terminal.

Project Type

Command-Line Application (CLI)
